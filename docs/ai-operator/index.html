Components

The four building blocks

Each piece is open-source, free, and runs entirely on your hardware. No cloud required beyond the Claude API.

01 — Input
🔇

faster-whisper (Voice Input)

A lightning-fast, locally-running speech-to-text engine. You speak; it transcribes immediately on your Mac with zero cloud latency. Based on OpenAI Whisper, optimised for Apple Silicon.

Python Local Apple Silicon Real-time
02 — Routing
⚡

OpenClaw / Dispatch

The central task router. When a transcribed command arrives it decides: is this a quick answer, a coding task, a browser action, or a file operation? It dispatches to the right specialised agent automatically.

Node / Python Agent router Context-aware
03 — Intelligence
🤖

Claude (Anthropic)

The brain. Claude receives the task with full context — what's on screen, what you said, what happened before — and produces a plan. It reasons step-by-step and can use tools: browser, terminal, files, APIs.

Claude 3 / 4 Tool use Long context Vision

Setup Guide

Get running in one afternoon

You need a Mac (M1 or later recommended), an Anthropic API key, and about 30 minutes.

1

Install core dependencies

Make sure you have Python 3.11+, Homebrew, and Node.js installed on your Mac.

# Install Homebrew (if not already installed) /bin/bash -c "$(curl -fsSL https://brew.sh/install.sh)" # Install Python and Node brew install python@3.11 node
2

Install faster-whisper for voice input

This runs speech-to-text locally on your Mac. No data ever leaves your machine.

pip install faster-whisper pyaudio sounddevice numpy # Test microphone access python3 -c "import sounddevice; print(sounddevice.query_devices())"
3

Set your Anthropic API key

Get your key from console.anthropic.com, then add it to your shell environment.

# Add to ~/.zshrc or ~/.bashrc export ANTHROPIC_API_KEY="sk-ant-your-key-here" # Reload your shell source ~/.zshrc
4

Clone and configure the AI Operator stack

Pull the dispatch layer and configure which agents Claude can route tasks to.

git clone https://github.com/bonuz-market/superpowers032026 cd superpowers032026 # Install dependencies pip install -r requirements.txt # Copy and edit config cp config.example.json config.json nano config.json
5

Grant screen recording & accessibility permissions

For Claude Computer Use to see and control your screen, macOS needs explicit permission.

# Open System Settings → Privacy & Security # Enable for your terminal app: # ✓ Screen Recording # ✓ Accessibility # ✓ Automation
6

Start the operator

Launch the main process. It will listen for your voice trigger word (default: "Hey Claude"), then wake up and take action.

# Start the AI operator python3 operator.py --mode voice # Or run as a background service python3 operator.py --daemon # View logs in real time tail -f ~/.ai-operator/logs/session.log
7

Try your first command

Say the trigger word and give a natural instruction. The operator will transcribe, plan, and act.

# Example voice commands you can say: "Hey Claude, open my email and summarise unread messages" "Hey Claude, take a screenshot and describe what you see" "Hey Claude, write a reply to the last Slack message" "Hey Claude, check if our website is down and send me a report"
Pro Tips

Make it work even better

Small tweaks that make a big difference in day-to-day use.

📋

Give Claude a context file

Create a context.md file with your name, projects, tools you use, and preferences. Claude reads it on every task.

🌐

Use a dedicated Mac Mini

A Mac Mini M2 ($600) makes a perfect always-on AI server. It uses under 8W idle and never interrupts your main machine.

🔒

Limit Computer Use scope

In config.json, restrict which apps Claude can control. This prevents accidents and keeps your data safe.

📄

Log everything

Enable full session logging. It's invaluable for reviewing what the AI did, debugging issues, and improving your prompts.

🌱

Start with small tasks

Begin with low-risk operations: reading email, summarising documents, searching the web. Build trust before automating critical actions.

🚨

Set a confirmation mode

For destructive actions (sending email, deleting files), configure Claude to always ask for verbal confirmation first.
